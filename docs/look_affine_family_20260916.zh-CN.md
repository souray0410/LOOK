# LOOK：统一线性／仿射修正家族（2026-09-16）

本轮研究冻结宿主后的向量修正：Y_hat = X + XW + b。数据拟合不更新宿主，不使用疾病标签作为回归目标；原dev分类选型仍使用标签。存在b时称仿射，training-free仅指无需宿主神经网络再训练，不代表不用数据估计参数。线性/低秩映射不保证数学上的一一对应、满秩或可逆。项目全名保留既有LOOK/Korrektur命名，本轮不自行重命名仓库。

## 与已有研究的关系

冻结同一宿主，保留原始任务、参与者划分、MHD V4、节点、父模型和全部结果。原三臂的接受预测直接以SHA引用，不覆盖、不重计科研重复。空间插值/直接PCA/平均池化回答表示问题；起点与逐层贪心回答部署位置问题；本补充回答固定表示和位置下如何估计修正矩阵。不立即将所有轴盲目笛卡尔展开，也不将末级结果推广为全部逐层结果。

所有81宿主（三疾病×三架构×三融合位置×三种子）分两个独立scope：terminal末级与progressive原标准LOOK选中位置。每scope新增五臂，共162个可领取case、810个新增方法视图、1620个纯缺失方向视图，新增神经网络训练0。每个case的拟合/节点数另记，不能称810次神经训练。

## 比较与共同条件

| 方法ID | 含义 | 主要约束 |
|---|---|---|
| shared_pca_ridge | 原PCA约束残差岭回归 | 固定PCA输入/输出子空间与均值 |
| pca_free_mean | 同PCA斜率、自由均值 | 只解除残差均值的子空间限制 |
| rrr_shared_intercept | 原低秩回归、PCA约束均值 | 自由斜率子空间，rank≤q |
| residual_rrr | 原低秩回归、自由均值 | rank≤q |
| residual_ridge | 无显式秩约束残差岭回归 | 不硬截断方向，保留L2惩罚 |
| pls_svd_ridge | 配对协方差方向＋岭回归 | SVD(XcᵀDc)左方向q维，向完整残差预测 |
| diagonal_ridge | 对角残差岭回归 | 逐坐标缩放/偏移，不混合特征 |
| orthogonal_alignment | 正交完整特征对齐 | QᵀQ=I，允许反射，W=Q−I |

前四臂是子空间×均值的2×2设计。PLS-SVD方向后接岭回归不是NIPALS/迭代PLSRegression，也不声称复现后者。参见 https://scikit-learn.org/stable/modules/cross_decomposition.html 。正交解来自SVD(XcᵀYc)，与SciPy orthogonal_procrustes核验。

同宿主采用原PCA选中的位置、空间表示、标准化、q、lambda；末级即便原候选被on/off规则关闭，仍比较相同候选，不按新分数删除臂。lambda保持原SSE尺度，不误转成均值损失。无秩约束仅相对于当前输入表示，不代表从原图起无压缩。正交约束在标准化坐标中定义，无岭惩罚；因此它是结构替代比较，不是只改变一个正则参数的等容量对照。对角及无秩约束方法也不强行配q，保存真实参数/储存/耗时。

逐层scope每臂沿固定站点顺序独立重拟合并应用自己的上游修正；因此后层特征会不同，这回答的是累积策略差异，不能当作每一层输入完全相同的局部实验。原标准LOOK选型不被补充方法改写。本轮是条件机制研究，不是各方法独立调参后的最佳性能竞赛。

## 预定统计与解释

16个成对定义及1个均值×子空间交互，分别报告缺OCT、缺CFP、两者指标均值，共51项每宿主比较族。比较清单由affine_protocol生成：四个因素差值、full-ridge减RRR、PLS减RRR、full-ridge减diagonal/orthogonal、八方法各减宿主，交互为(RRR自由−RRR约束)−(PCA自由−PCA约束)。旧比较族不改写；相同对比在全研究主张中需按权重去重。

10000次参与者级配对bootstrap，三种子共用索引，先算各模型F1后平均，不堆成三倍独立人数。给普通和族内max-|t|同时区间，零方差单列；本模块不是整个LOOK研究全局校正。±1 pp维持原研究参考范围。报告保留所有负收益、完整输入、混合缺失、拟合MSE、参数与成本。特征误差下降不代表分类更好，当前dev数据不能当确认性独立test证据。

## 自动执行与验收

单宿主3416全部八臂及匹配报告技术接受后，自动放行3417/3418，无效果或显著性门槛。三种子齐全自动触发该宿主scope统计。terminal依赖原末级接受（可复用train缓存），progressive依赖原线性三臂接受。共享原子领取和GPU dispatcher，新feed无独立申卡owner。未知类先真实Slurm资源profile；terminal申请128GiB RAM、progressive512GiB，worker分别100/384GiB，不静默减维。默认48h与两张generic最低保留不变。

增量统计按缓存分片或原训练批次保存；逐节点与已完成映射有内容SHA和上游身份；到期保留同run重新领取，未提交的分解/评价单元允许重算，不声称逐浮点操作续接。原健康源码不热改。旧产物继续旧版本，新schema只有一个读取标准，不加服务器来源兼容分支。

验收包含独立公式/参考实现、仿射性质、自由/约束均值斜率恒等、q满维与岭回归等价、对角无混合、Q正交、零残差、MHD原Node ID/宿主/BN冻结、重载、随机状态、恢复、配对身份、篡改拒绝、test拒绝和资源峰值。代码测试、部署、正式运行与科研结果接受分别记录。
