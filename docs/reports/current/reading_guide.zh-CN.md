# LOOK：先看研究问题，再看配置编号

本项目问的是：两种图像中缺了一种时，能否用线性矫正让原模型恢复部分预测能力？CFP是彩色眼底照片，OCT是光学相干断层扫描；“缺OCT”表示只留下CFP，反之亦然。

|研究问题|比较什么|当前证据/尚缺内容|
|---|---|---|
|拟合方向怎样选|PCA自由均值与自由低秩残差；同一冻结宿主、数据、秩与正收益树规则|R50/R18小队列均已完整验收，未见统一赢家；见小队列页|
|差异是否只来自树路径不同|固定同一个空前缀、同一位置比较拟合|36项已复用分析；λ仍按原规则选择，不能叫固定λ机制实验|
|老师：已有缺失处理方法能否加LOOK|需要真正缺失模态策略A，与冻结同一A后的A+LOOK|尚未完成；MMTM只保留宿主兼容/组装证据，候选见research_decisions/missing_method_evidence_20260919.md|
|分支融合位置是否影响矫正|中层、深层、特征层宿主，保持其他条件匹配|既有病例和后继登记保留，未形成全部宿主匹配结论|
|缩放、秩、均值约束和矫正起点的影响|每次改变一个因素，明确完整方法与固定前缀机制区别|原批准清单保留，优先拟合核心与老师问题；不因已有局部高分取消必要对照|
|结果是否可靠推广|大队列、重复种子、更多合格方法/任务|Ibex继续独立正式证据；小队列单种子不替代正式重复，test封存|

正收益树会在每个已接受前缀后尝试所有下游位置，保留全部严格正收益分支。相同规则下，它包含best-forward的路径，故不为验证这个包含关系重复做性能实验；成本和泛化仍不能由包含关系推断。

ResNet18/50中的数字是骨干架构名称；3416是随机种子，不是病例数。q=32/rank32表示矫正的秩限制；x16表示当前协议的空间降采样配置，不是训练轮数。Macro-F1按类别分别算F1再取平均，不等于准确率；“+1个百分点”表示例如60%变成61%。两种拟合都允许自由均值/截距，并非自由与固定均值的比较。

每页按“问题→固定/改变条件→结果与反例→结论边界→下一步”讲述。具体样本量、空间缩放实现、宿主初始化/停止规则、最终路径、区间及证据截止在[累计配置页](small_cohort/README.md)。不把不同疾病/队列的数值混排；未跑的情况明确保留，不填零。
