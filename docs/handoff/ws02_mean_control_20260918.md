# WS02：固定斜率、λ与空前缀的均值诊断

目的：分离拟合方法差异中的均值项，不用另一棵独立搜索树冒充单因素机制消融。原自由均值结果继续有效。

单种子3416、原1264 train/296 dev青光眼小队列，ResNet18普通宿主和MMTM适配宿主两个已验收配置，各2拟合家族×2缺失×9位置，共72个固定单点对照。复用全部已拟合根候选，包括负收益位置；不重训、不重新拟合、不增种子。

对残差映射 (x−μx)W+μΔ，仅把μΔ改成μΔQᵀQ；保持各自W、λ、输入均值、完整训练PCA基Q和同一空前缀。Q为已接受的32维完整特征PCA基。两个家族之间不声称同斜率；每个家族内部严格只变均值。自由结果现场重放后与旧预测逐元素核对；派生算子保存/加载后评价。每项单独SHA缓存和完成回执，新增结果进同一表。

这是强制单点诊断，不是独立优化约束均值方法或新的完整树；后者身份仍保留。F1/AUROC/NLL/Brier均保存。此处按已看dev作探索性逐位置描述，不挑最高一项宣称显著、稳定或泛化。主任务训练/停止/划分不变，test封存。

实施入口look.studies.cohort_mean_control；单GPU0沿原GPU锁，资源余量10GiB/host15%。实际启动与验收须以运行回执补充。
