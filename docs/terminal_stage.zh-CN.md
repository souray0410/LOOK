# 提前执行已批准的单末级机制阶段

日期：2026-09-15。为本周提供可验收的匹配阶段结果，移除“全部层PCA完成才可计算单末级修正”的非必要执行依赖。完整逐层LOOK及空间处理研究保留；本阶段不得计为完整LOOK研究单元完成。

## 固定研究内容

现有81个宿主均保留，接受宿主后即可开始；每组先3416技术验收，再3417和3418，不要求收益为正。来源优先按已确定疾病、架构、middle/deep/features和种子顺序，不看分数排序。

只使用fusion_participant_feature的参与者向量。此处空间插值、平均池化均不适用，不能用本结果替代空间处理对照。复用原宿主、完整train/dev、原最大PCA秩512、原候选维度与train GCV。PCA仍为原IncrementalPCA；缓存保持原batch及顺序，不换成另一种SVD。

输出无修正宿主与标准single_final（包括原dev严格改善启用规则）。另以single_final搜索中的最佳候选q/lambda为共同设置，对比共享PCA岭回归、匹配均值的RRR、完整均值的RRR。即使原启用规则关闭该候选，仍单独展示三种实际映射，避免只保留正结果。此比较条件于PCA所选配置，不声称各方法均独立优化到最佳。

## 执行、复用与验收

- 冻结宿主和BN，一次缓存train/dev三种输入状态的末级特征与预测。参与者、眼别及标签顺序不变；逐batch哈希及游标允许恢复。缓存位于受限存储。
- 原始数值拟合器接收可选已核验特征迭代器，默认路径不变。缓存只去除重复相同前向，不减少拟合样本或候选。
- 缓存每个batch与实际MHD分类边输出完全一致；正式每个映射对完整dev再做MHD前向逐项核对。产物严格重载、冻结状态、节点身份均需通过。
- 预检只用train，完整rank512和实际2048维工作空间；预检结果不进入正式评价。显存/主机内存经准入，沿用现有原子领取和48小时资源规则。
- 缓存按batch恢复，PCA与统计/矩阵求解按阶段恢复；不承诺SVD内部可暂停。原源目录和旧任务输出只读，不提前覆盖原single_final产物。
- 原全流程以后产出的single_final与本阶段需通过数据、配置、数值等价复用审计才合并；目前分别标识，不能直接去重为同一已完成任务。

正式报告列两种缺失输入、完整输入、混合缺失及三个线性映射配对比较；10,000次参与者bootstrap。预先登记三个映射间的比较、各映射减宿主，以及标准single_final减宿主，共7个比较×两种缺失及缺失均值＝21个对比，单独构成比较族。周报必须明确此为单末级条件机制证据，不能声称内部逐层LOOK已有效，也不能推断空间压缩方法孰优。
